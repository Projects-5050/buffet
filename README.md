# طلبات فريج بن عاقول

تطبيق ويب لطلب الأكل من مطعم **فريج بن عاقول** في البحرين.

- قائمة مصوّرة مع سلة واختيار الفرع (9 فروع) أو التوصيل
- قسم البوفية: ثلاث خطط (7 أطباق 3.500، 8 أطباق 4.000، 9 أطباق 4.500 د.ب) يختار الزبون أصنافها، ويُرسل الطلب للفرع عبر واتساب
- الدفع بتحويل آيبان أو BenefitPay مع رفع صورة الإيصال
- متابعة حالة الطلب للزبون
- لوحة الفرع (`#board`) لتأكيد التحويلات وتحريك الطلبات، مع إعدادات الدفع والأسعار والصور وأصناف البوفية وأرقام الواتساب

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages على فرع `main`.

## ملاحظة
النسخة الحالية تحفظ الطلبات في متصفح الجهاز (localStorage)، فلوحة الفرع ترى الطلبات المرسلة من نفس الجهاز فقط.
ربط قاعدة بيانات مشتركة (مثل Supabase) هو الخطوة التالية لاستقبال طلبات الزبائن من جوالاتهم.
